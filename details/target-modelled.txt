## System delineation

The prediction goal defines the system boundary -- more or less. Which drivers and processes to include, and at which spatial and temporal resolution to represent the system, is a highly iterative trial-and-error process. For any given set of processes included, a <a href=#sensitivity-analysis>sensitivity analysis</a> will tell whether it is really relevant for the system state of interest. Whether a model should aim for complexity or simplicity is a <a href=#ContentiousSimplicityComplexity>contentious issue</a>. 

If the effect of a driver is highly „context dependent“ (i.e. changes from one set of drivers to another; in other words: a statistical interaction), then the system is probably larger than currently considered.<sup class="cite-ref" data-cite="Spake 2023"></sup>
